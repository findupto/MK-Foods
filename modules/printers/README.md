# Printer Routing

- Configure printers by station, device, Bluetooth MAC/address, connection type, and location.
- Route food tickets to kitchen stations and beverage tickets to bar/drink stations based on item/category rules.
- Print customer receipts and payment proofs.
- Support ticket templates, copies, headers/footers, and paper-width configuration.
- Support automatic paper-cut commands where the printer supports them.
- Queue print jobs locally so WAN outages do not stop printing.
- Track print status, retries, failures, and duplicate-prevention IDs.
- Settings must provide a printer test action and Bluetooth MAC configuration for the business default printer.
