# Audit & History

Searchable immutable audit events include user, role, device, location, timestamp, action, entity, entity ID, before/after values where safe, reason, and correlation/event ID.

Track login/logout/lockout, refunds, voids, discounts, cash drawer events, menu changes, inventory adjustments, supplier changes, permissions, settings, dispatch, KDS changes and synchronization errors.

Audit data is retained according to configurable policy and protected from normal user modification/deletion.
