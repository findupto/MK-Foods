# Backup & Recovery

- Automatic encrypted local and cloud backups according to retention policy.
- Backup integrity checks using checksums and schema/version metadata.
- Restore workflow with pre-restore validation, explicit admin confirmation and audit record.
- Disaster recovery runbook covering device loss, database corruption, cloud outage and credential compromise.
- Complete encrypted business export/import including configuration, menu, customers, suppliers, inventory and operational records subject to privacy/retention rules.
- Recovery-point and recovery-time objectives are configurable per deployment.
