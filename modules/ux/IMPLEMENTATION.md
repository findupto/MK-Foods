# UX

- Global search across orders, receipts, customers, menu, suppliers and inventory.
- Advanced filters/sorting by date, price, staff, item, location and status.
- Keyboard shortcuts for common POS actions plus barcode/scanner support.
- Touch-optimized large controls and fast category/item navigation.
- Receipt preview before printing and reprint confirmation.
- Dark mode and accessibility-aware status presentation.
- Notifications for low stock, late kitchen tickets, sync errors, printer failures and cash variance.
- Explicit loading, success, error and retry states.
- Confirmation dialogs for destructive or financial operations.
- Useful empty states with a clear next action.
- Responsive kiosk interface with simplified customer-facing navigation and restricted administrative access.
