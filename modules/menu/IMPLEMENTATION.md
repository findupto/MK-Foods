# Advanced Menu

- CRUD for categories, items, modifier groups, modifiers, recipes and ingredients.
- Multiple prices by order channel, location, size or customer tier.
- Scheduled prices and availability with effective start/end timestamps.
- Tax classes and location-specific tax rules.
- Location-specific menu overrides with central publishing/versioning.
- Separate POS, kiosk, delivery and other channel catalogs.
- Item images with local cache and cloud media synchronization.
- CSV import validates headers, types, duplicate IDs/SKUs, categories, prices, tax classes and references before changing data.
- Import preview shows create/update/delete candidates and validation errors; commit requires explicit confirmation and permission.
- Export includes version metadata and stable IDs for round-trip editing.
